Your computer’s calm, local assistant — built to stay fast on ordinary laptops.

J.A.R.V.I.S [EARLY ACCESS] is a personal AI helper for Windows that you run on your own machine. It listens when you allow it, talks back, opens apps and sites, and helps with everyday PC tasks — without needing a high-end GPU or a huge download. It was designed for real hardware such as an Intel Core i3, 8 GB of RAM, and a hard disk, so it stays usable on school and home laptops. Permissions start off: the microphone, files, and apps stay private until you turn them on. Phase 1 shipped the core assistant. Phase 2 (Early Access Final Act) added voice reliability, extra Windows tools, themes, plugins, and this download site.

Features

What the desktop app can do today (Windows ZIP is the full product).

Phase 1 [EARLY ACCESS]

  • Wake phrase: “Jarvis Activate”
  • Voice replies and text chat
  • Conversation mode (follow-up questions without repeating the wake phrase)
  • English, Hindi, and Punjabi
  • Open apps, folders, and websites
  • Launch ChatGPT, Gemini, Copilot, and similar AIs
  • System info, battery, gaming / performance modes
  • Safe file helper (your user folders only)
  • WhatsApp Web: prepare a message, confirm before anything is sent
  • Personality: Professional, Friendly, Playful
  • Themes, HUD / waveform / robot animations
  • Permission manager (grant and revoke anytime)
  • Share Jarvis — public project link only, never your private files

Phase 2 [EARLY ACCESS FINAL ACT]

  • Microphone auto-detect, mic test, speaker test, voice diagnostics
  • Fixes for “Speaking” with no sound, plus TTS recovery
  • More reliable wake phrase matching
  • After activate: “How would you like to use Jarvis?”
  • Modes: Full Jarvis, Sidebar Companion, Voice Only (remembered)
  • “Jarvis Standby” to stop listening
  • Notes, clipboard, timers, calendar, brightness help, screenshots
  • Plugins: calculator, translator, weather, Steam helper, music helper
  • New themes (armor, green power, shield, cosmic, speed, light mode)
  • Layouts: full window, floating, sidebar, compact, performance mode
  • Bug / glitch report box in Settings
  • This website with a device + ZIP / portable picker (no APK)

Download

Pick which device you want, then the package (Windows ZIP or portable pack). Phones use the web companion. Public project files only — no passwords, API keys, or personal settings.

Open web companion All releases

Windows installer: unzip the ZIP, then run INSTALL-WINDOWS.bat (creates Desktop shortcut, installs Python packages for this user).
Portable: unzip and run Start_JARVIS.bat. Linux/macOS scripts are in installers/.

Windows

Full assistant. Choose ZIP (installer) or portable pack. Status: available.

Android

Install the APK (WebView of the live companion, camera/mic allowed) or ZIP / Add to Home Screen.

iPhone / iPad

No native iOS app. Use Open web companion, then Share → Add to Home Screen.

Linux, macOS & Web

Linux/macOS: experimental Python scripts inside the Windows ZIP. Web: no install — open the companion in a browser.

Privacy

Downloads from this site are the public project only. They do not include your chats, logs, API keys, or Windows settings. On the PC app, microphone and file access stay off until you allow them in Settings.
