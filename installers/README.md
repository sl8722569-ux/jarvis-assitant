# J.A.R.V.I.S installers

Phase 1 [EARLY ACCESS] · Phase 2 [EARLY ACCESS FINAL ACT]

| OS | Installer | What you get |
|----|-----------|----------------|
| Windows | `windows/Install-JARVIS.bat` | Copies app, venv, pip packages, Desktop + Start Menu shortcuts |
| Linux | `linux/install-jarvis.sh` | User install under `~/.local`, `jarvis` command, `.desktop` launcher |
| macOS | `macos/install-jarvis.sh` | User install under `~/Applications/JARVIS` |
| Android | website PWA + ZIP companion | No native APK. Chrome → Add to Home Screen |
| iOS | website PWA | Add to Home Screen in Safari |

Windows ZIP of the whole project remains the portable option (no install).

Uninstall Windows: run `Uninstall-JARVIS.ps1` in `%LOCALAPPDATA%\JARVIS`.
